# Android TV listing screenshots

Do not put Robolectric baselines or mockups here. Play listing screenshots must show the shipping
Play-signed build on an actual Android TV surface with accurate data.

Capture four 1920 × 1080 opaque PNGs from the reference Shield after the first Internal-track install:

1. Watching with transient channel/programme chrome visible.
2. Surf rail over still-playing video.
3. Guide with programme artwork and focused episode detail.
4. Pairing or a second Guide/Watching state that communicates the product without exposing a private
   server hostname, pairing code, user identity, or private library metadata.

Review every image at full size for overscan, clipping, stale time, private information, and visual
accuracy before uploading it to Play Console.
